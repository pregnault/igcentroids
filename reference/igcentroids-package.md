# igcentroids: Information-geometric centroids for categorical distributions, positive arrays and more

This package implements several approximation algorithms of the
symmetric Kullback-Leibler centroid, also called symmetrical
Kullback-Leibler centroid or symmetrized Kullback-Leibler centroid, or
Jeffreys centroidc.
